# FarsiFlow | فارسی‌یار

**فونت دلخواه شما، برای متن فارسی خواناتر در وب.**

![فارسی‌یار؛ انتخاب فونت، تنظیم جهت متن و افزودن فونت شخصی](assets/farsiflow-banner-fa.png)

فارسی‌یار یک افزونهٔ رایگان و متن‌باز برای Chrome است که به شما کمک می‌کند فونت و نمایش متن فارسی را در وب‌سایت‌های دلخواه تنظیم کنید. وقتی در یک صفحه، فارسی و انگلیسی کنار هم قرار می‌گیرند یا فونت پیش‌فرض سایت برای مطالعه مناسب نیست، می‌توانید فونت فارسی، اندازهٔ نوشته، فاصلهٔ خطوط و جهت نمایش متن را متناسب با نیاز خود تغییر دهید.

این افزونه برای محدودهٔ پیام‌ها در **ChatGPT، Gemini و Claude** قواعد ویژه دارد و می‌توانید آن را برای سایت‌های دیگر هم فعال کنید. تنظیمات هر دامنه جداگانه ذخیره می‌شود؛ بنابراین می‌توانید برای هر سایت تجربهٔ خواندن متفاوتی داشته باشید.

> نسخهٔ فعلی: **۱٫۰٫۴** · Chrome **۱۲۰ یا جدیدتر** · Manifest V3 · مجوز کد: **MIT**
>
> تصویر بالا، تصویر معرفی مفهومی افزونه است. افزونه در حال حاضر از طریق نصب دستی قابل استفاده است و هنوز در Chrome Web Store منتشر نشده است.

## فارسی‌یار چه کاری انجام می‌دهد؟

- **انتخاب فونت فارسی:** وزیرمتن، شبنم و ساحل همراه افزونه هستند و به نصب جداگانهٔ فونت روی سیستم نیاز ندارند.
- **افزودن فونت شخصی:** فایل‌های `WOFF2`، `WOFF`، `TTF` و `OTF` را اضافه کنید یا نام خانوادهٔ یک فونت نصب‌شده روی سیستم را وارد کنید. فایل فونت متغیر نیز پشتیبانی می‌شود.
- **تنظیم مستقل هر سایت:** فونت، اندازه، فاصلهٔ خطوط و وضعیت فعال‌بودن افزونه را برای هر دامنه جدا تعیین کنید.
- **نمایش بهتر متن ترکیبی:** حالت هوشمند، جهت پاراگراف را با بررسی متن تعیین می‌کند. حالت‌های «اولین حرف»، راست‌چین متن فارسی و «فقط فونت» هم در دسترس‌اند.
- **حفظ فونت انگلیسی:** پوشش فونت جایگزین به حروف فارسی و عربی محدود است تا فونت حروف انگلیسی سایت حفظ شود.
- **توجه به کد و فرمول:** لینک‌ها، کدها و قطعه‌های انگلیسیِ دارای عنصر مستقل در صفحه، جهت نمایش جداگانه دارند.
- **واکنش به محتوای تازه:** متن‌هایی که پس از بازشدن صفحه اضافه می‌شوند، از جمله پاسخ‌های در حال تولید، دوباره بررسی می‌شوند.
- **تنظیم خوانایی:** اندازهٔ متن از ۸۰ تا ۱۶۰ درصد و فاصلهٔ خطوط قابل تنظیم است.
- **پشتیبان تنظیمات:** تنظیمات را به‌صورت فایل `JSON` خروجی بگیرید و دوباره وارد کنید.

رابط افزونه فارسی است، حالت تیره دارد و پردازش متن به‌صورت محلی انجام می‌شود.

## نصب از گیت‌هاب

برای استفاده از افزونه، نیازی به Node.js، Python یا ساخت پروژه ندارید.

1. در صفحهٔ مخزن، از **Code → Download ZIP** فایل پروژه را دریافت و از حالت فشرده خارج کنید.
2. در Chrome آدرس `chrome://extensions` را باز کنید.
3. گزینهٔ **Developer mode** را روشن کنید.
4. روی **Load unpacked** بزنید و پوشهٔ **`extension`** داخل پروژه را انتخاب کنید؛ پوشه‌ای که فایل `manifest.json` در آن قرار دارد.
5. در تنظیمات افزونه، سایت دلخواه را فعال و درخواست دسترسی Chrome را تأیید کنید.
6. صفحهٔ سایت را باز یا بازخوانی کنید و از پنجرهٔ افزونه، فونت و تنظیمات نمایش را تغییر دهید.

اگر فایل مستقل `FarsiFlow-1.0.4-Chrome.zip` را دریافت کرده‌اید، آن را استخراج کنید و در مرحلهٔ چهارم، همان پوشه‌ای را انتخاب کنید که `manifest.json` مستقیماً داخل آن است.

**برای به‌روزرسانی:** فایل‌های افزونه را جایگزین کنید، در `chrome://extensions` دکمهٔ بازخوانی افزونه را بزنید و سپس تب‌های باز سایت‌ها را نیز بازخوانی کنید. پوشهٔ نصب را پس از نصب حذف یا جابه‌جا نکنید.

## شروع پیشنهادی

برای مطالعهٔ گفتگوهای فارسی، با فونت **وزیرمتن** و جهت **هوشمند** شروع کنید. اگر نوشته‌ها کوچک‌اند، اندازه را روی ۱۱۰ یا ۱۲۰ درصد و فاصلهٔ خطوط را روی ۱٫۸ قرار دهید. در محیط‌های هوش مصنوعی، محدودهٔ **هوشمند** نقطهٔ شروع مناسبی است.

اگر فقط می‌خواهید فونت تغییر کند، حالت **فقط فونت** را انتخاب کنید. اگر جهت یک متن خاص مناسب نیست، حالت **اولین حرف** را امتحان کنید یا تنظیمات همان سایت را تغییر دهید.

برای افزودن فونت شخصی، صفحهٔ تنظیمات را باز کنید و فایل فونت را وارد کنید. هر فایل می‌تواند حداکثر **۲ مگابایت** باشد و مجموع فایل‌های واردشده حداکثر **۵ مگابایت** است. برای فونت سیستم، نام دقیق خانوادهٔ فونت لازم است؛ در صورت در دسترس نبودن آن، وزیرمتن جایگزین می‌شود.

## حریم خصوصی و دسترسی‌ها

فارسی‌یار برای نمایش متن، محتوای همان صفحه را در مرورگر بررسی می‌کند؛ متن صفحات و گفتگوها را به سرور ارسال نمی‌کند و تاریخچهٔ گفتگوها را ذخیره نمی‌کند. تنظیمات و فونت‌های واردشده در فضای محلی Chrome نگهداری می‌شوند. افزونه تبلیغات، ابزار رهگیری و همگام‌سازی ابری ندارد و فونت‌های پیش‌فرض داخل بسته هستند.

دسترسی به سایت‌ها **اختیاری** است و هنگام فعال‌کردن هر سایت، با تأیید شما داده می‌شود. می‌توانید افزونه را برای همان سایت خاموش کنید یا مجوز آن را لغو کنید.

| مجوز | کاربرد |
| --- | --- |
| `storage` | ذخیرهٔ تنظیمات و فونت‌های شخصی |
| `activeTab` | تشخیص سایت تب فعال در پنجرهٔ افزونه |
| `scripting` | ثبت و اجرای کد تغییر نمایش در سایت‌های مجاز |
| دسترسی اختیاری به دامنه | اعمال تنظیمات در سایتی که خودتان فعال کرده‌اید |

متن کامل سیاست حریم خصوصی در [این فایل](store-assets/privacy-policy.html) قرار دارد.

## محدودیت‌های فعلی

- افزونه ظاهر متن را تغییر می‌دهد؛ ترجمه، اصلاح نگارش یا بازنویسی محتوای پیام انجام نمی‌دهد.
- جهت متن با بررسی حروف تخمین زده می‌شود. نمایش عبارت انگلیسی درون یک گرهٔ متن همچنان به قواعد Unicode مرورگر وابسته است؛ نتیجهٔ همهٔ ترکیب‌های فارسی، انگلیسی و نشانه‌گذاری یکسان نیست.
- صفحات داخلی Chrome، Chrome Web Store و نمایشگر PDF داخلی قابل تغییر نیستند. متن داخل تصویر، `canvas` و PDF نیز پشتیبانی نمی‌شود.
- محتوای داخل Shadow DOM پشتیبانی اختصاصی ندارد. فریم‌های داخلی صفحه فقط با مجوز دامنهٔ خودشان پردازش می‌شوند؛ مجوز زیردامنه‌ها نیز مستقل است.
- نتیجه در سایت‌های مختلف به ساختار صفحه و قواعد نمایش آن سایت بستگی دارد. تغییر ساختار سرویس‌ها ممکن است به به‌روزرسانی افزونه نیاز داشته باشد.
- افزونه چیدمان کل صفحه یا ترتیب ستون‌های جدول را تغییر نمی‌دهد.

## گزارش مشکل و مشارکت

اگر بخشی از یک صفحه درست نمایش داده نمی‌شود، در بخش **Issues** مخزن، نسخهٔ افزونه، نسخهٔ Chrome، دامنهٔ سایت، بخش مشکل‌دار و مراحل تکرار مشکل را بنویسید. در صورت افزودن تصویر، اطلاعات شخصی و محتوای خصوصی گفتگوها را بپوشانید. همچنین مشخص کنید مشکل با حالت «فقط فونت» هم رخ می‌دهد یا فقط هنگام تغییر جهت متن دیده می‌شود.

پیشنهاد قابلیت، گزارش ناسازگاری و Pull Request برای بهبود پروژه پذیرفته می‌شود.

## توسعه و آزمایش

پیش‌نیازهای توسعه: Node.js 20 یا جدیدتر و Python 3.10 یا جدیدتر. افزونه در زمان اجرا وابستگی npm ندارد.

```bash
npm install
npm test
npx playwright install chromium
npm run test:renderer
npm run test:browser
npm run package
```

دستور آخر، بستهٔ نصب Chrome و بستهٔ کامل پروژه را داخل `dist/` می‌سازد. برای استفاده از Chrome for Testing نصب‌شده، متغیر `FARSIFLOW_CHROME` را به مسیر فایل اجرایی آن تنظیم کنید.

**وضعیت اعتبارسنجی نسخهٔ ۱٫۰٫۴:** ۳۱ آزمون منطق و شبیه‌سازی DOM/API موفق بوده‌اند. آزمون رندر با API شبیه‌سازی‌شده، جایگزین اجرای واقعی افزونه نیست. یکپارچگی این نسخه با Chrome کامل و حساب‌های واقعی سایت‌ها هنوز تأیید نشده است؛ پیش از انتشار یک نسخهٔ پایدار، آزمون مرورگر و بررسی دستی سایت‌های هدف لازم است.
