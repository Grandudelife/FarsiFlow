# بنچمارک و تصمیم طراحی

تاریخ بررسی: ۷ اکتبر ۲۰۲۶. این مقایسه بر صفحهٔ معرفی فونت ایران، فهرست فعلی Chrome Web Store و مخزن عمومی آن استوار است. افزونهٔ مرجع به‌صورت نصب‌شده آزمایش نشده است؛ مخزن عمومی دیده‌شده متعلق به نسخه‌ای قدیمی‌تر از فهرست فعلی است. رفتار داخلی نسخهٔ ۵٫۲٫۲ از روی کد ۲۰۱۸ نتیجه‌گیری نشده است.

## مقایسهٔ قابلیت‌های مستند و پیاده‌سازی این بسته

| موضوع | فونت ایران؛ منابع مشاهده‌شده | فارسی‌یار |
|---|---|---|
| تغییر فونت فارسی سایت‌ها | مستند در معرفی و استور | انتخاب مستقل برای هر دامنه |
| افزودن سایت دلخواه | مستند در معرفی | پنجرهٔ سایت فعلی و ورودی دامنه در تنظیمات |
| افزودن فونت دلخواه | مستند در فهرست فعلی استور | فایل فونت یا نام دقیق فونت نصب‌شده |
| بدون نصب فونت در سیستم | مستند برای فونت‌های همراه | فونت‌های همراه و فایل واردشده؛ فونت سیستم به نصب نیاز دارد |
| اندازه و فاصلهٔ خطوط | تنظیمات در سورس عمومی قدیمی وجود دارد؛ خط ارتفاع در CSS متغیر تعریف می‌شود | تنظیم مستقل روی بلوک‌های فارسی؛ حفظ اندازهٔ پایهٔ سایت |
| فعال/غیرفعال و پیش‌فرض‌ها | در سورس عمومی قدیمی وجود دارد | پیش‌فرض، override سایت، خاموشی و لغو مجوز |

| متن فارسی و انگلیسی ترکیبی | قابلیت تخصصی در صفحات مشاهده‌شده توضیح داده نشده | جهت هر پاراگراف؛ استقلال عناصر انگلیسی، کد و فرمول |

| فونت‌های تجاری فونت ایران | مجوز فقط در چارچوب همان افزونه طبق صفحهٔ معرفی | بازنشر نشده؛ وزیرمتن، شبنم، ساحل با SIL OFL |
| سورس | مخزن عمومی موجود است | کد مستقل، خوانا و بدون runtime dependency |

## قواعدی که کیفیت متن ترکیبی را حفظ می‌کنند

1. **جهت در سطح بلوک متن:** انگلیسی مستقل LTR؛ فارسی غالب RTL. نام محصول انگلیسی در ابتدای جملهٔ فارسی به‌تنهایی باعث LTR شدن جمله نمی‌شود. تشخیص هوشمند یک heuristic است؛ حالت اولین حرف و حالت بدون تغییر جهت برای استثناها وجود دارد.
2. **بدون وارونه‌سازی کلی صفحه:** flex/grid اصلی، دکمه‌ها، ترتیب جدول و ناوبری با direction روی root دستکاری نمی‌شوند. در سایت‌های هوش مصنوعی، اصلاح جهت و اندازه به محدودهٔ پیام‌ها محدود می‌شود.
3. **جداسازی بخش فنی:** pre/code/kbd/samp، فرمول‌های شناخته‌شده و لینک یا عنصر انگلیسی موجود با CSS isolate از متن فارسی جدا می‌شوند. از bidi-override استفاده نشده است.
4. **فونت فارسی مستقل از لاتین:** FontFace با محدودهٔ Unicode فارسی/عربی بارگذاری می‌شود؛ فونت اصلی لاتین سایت در fallback باقی می‌ماند. وزن متن بولد از سایت حفظ می‌شود؛ فایل همراه معمولی و ضخیم موجود است.
5. **کادر نوشتن:** dir=auto و plaintext؛ مقدار input/textarea و DOM کادر ویرایش بازنویسی نمی‌شوند. فیلد password، email، url و number تغییر نمی‌کنند.
6. **سازگاری با پاسخ پویا:** مشاهدهٔ DOM و متن، دسته‌بندی با requestAnimationFrame، بازگردانی نشانگرهای اختصاصی هنگام خاموشی. wrapper یا کاراکتر پنهان اضافه نمی‌شود.
7. **سایت‌های دارای CSP:** CSSStyleSheet ساخته‌شده و FontFace مبتنی بر بایت، بدون stylesheet یا font URL خارجی. این رفتار با یک fixture دارای محدودیت style/font آزمایش شده است.

## حدود مقایسه

«هم‌ارزی قابلیت» به معنی کپی نام، برند، فونت‌های تجاری یا تضمین رفتار تمام سایت‌ها نیست. متن‌های فاقد نشانه‌گذاری جدا برای هر عبارت انگلیسی به الگوریتم Unicode مرورگر تکیه دارند. کادر ویرایش، انتخاب و کپی روی حساب واقعی و نسخهٔ جاری سرویس‌ها قبل از انتشار باید بررسی شود.
