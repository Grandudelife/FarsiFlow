# فارسی‌یار ۱٫۰٫۳ — رسیدگی به قطع ارتباط پس از Reload

تصویر خطا مربوط به یک تب Gemini است: Extension context invalidated در بررسی دوره‌ای مجوز content.js. از این تصویر نمی‌توان نتیجه گرفت درخواست دسترسی LinkedIn شکست خورده است.

بعد از Reload، به‌روزرسانی، غیرفعال‌کردن یا حذف افزونه، کد باقی‌مانده در تب‌های قدیمی ممکن است ارتباط معتبر با Chrome API نداشته باشد. sendMessage در این وضعیت می‌تواند به‌صورت همزمان throw کند؛ catch متصل به Promise این خطا را نمی‌گرفت.

اکنون فراخوانی API داخل try/await/catch انجام می‌شود. هنگام قطع ارتباط، موتور قدیمی متوقف و تغییرات آن پاک می‌شوند، بررسی دوره‌ای قطع و شنونده‌های ورودی حذف می‌شوند. بررسی‌های بعدی و refresh داخلی، API قدیمی را دوباره فراخوانی نمی‌کنند. لغو عادی مجوز نیز وضعیت گزارش‌شده را به no-permission تغییر می‌دهد.

۲۷ آزمون Node موفق‌اند؛ آزمون تازه، خطای همزمان دقیقِ تصویر را روی کد قبلی بازتولید کرد و پس از اصلاح موفق شد. آزمون رد Promise و لغو مجوز نیز موفق است. رندر واقعی Chrome و حساب‌های واقعی سرویس‌ها در این نوبت آزمایش نشده‌اند. گزارش قدیمی رندر در بسته مربوط به نسخهٔ ۱٫۰٫۰ است.

## نصب و رفع وضعیت تب‌های قبلی

۱. ZIP نسخهٔ Chrome را باز و فایل‌ها را در همان پوشهٔ نصب قبلی جایگزین کنید.
۲. در chrome://extensions روی Reload بزنید و نسخهٔ 1.0.3 را بررسی کنید.
۳. تب‌های باز Gemini، LinkedIn، ChatGPT و Claude را که افزونه روی آن‌ها فعال است رفرش کنید؛ این مرحله کد باقیماندهٔ نسخهٔ قبلی را کنار می‌گذارد.
۴. در صفحهٔ خطاها Clear all را بزنید تا رکورد قبلی حذف شود.
۵. در همان تب LinkedIn پنجرهٔ افزونه را باز کنید و وضعیت واقعی یا خطای تازه را بررسی کنید.
